# Происхождение кода и сторонние условия

## Собственный код

Оригинальный код и изменения авторов Qdynn-Bridge предоставляются по [MIT](LICENSE). Эта лицензия не переоформляет права на исходный код, заимствованный у других авторов. Значение `license = "MIT"` в Cargo.toml описывает выбор лицензии для собственного кода проекта.

## Telegram WEB Proxy

Архитектура, wire contract и клиентский bridge основаны на [telegramdesktop/tproxy-server](https://github.com/telegramdesktop/tproxy-server). Референсная ревизия при разработке: `c8adb8b7c6b7fc46c12ae3acb68be9070c26a8e8`.

`crates/qdynn-server/src/bridge.js` содержит адаптированные фрагменты JavaScript из [internal/bridge/page.go](https://github.com/telegramdesktop/tproxy-server/blob/c8adb8b7c6b7fc46c12ae3acb68be9070c26a8e8/internal/bridge/page.go). Структура HTML/CSP в `bridge_html.rs` также следует исходному bridge. Протокол и нормативные векторы описаны на основе upstream. Qdynn-Bridge добавляет Rust relay, lifecycle/recovery, limits, наблюдаемость и средства эксплуатации; это не официальный продукт Telegram.

**Незавершённая проверка перед публичным распространением:** при подготовке 19.10.2026 отдельный файл лицензии `tproxy-server` в доступных материалах не найден; GitHub license endpoint вернул 404. Это не подтверждает MIT, GPL или разрешение на перелицензирование заимствованных фрагментов. Лицензия другого репозитория Telegram, например `tdesktop`, не переносится на `tproxy-server` автоматически. Для заимствованного кода нужно получить/подтвердить применимые условия у его правообладателя и сохранить соответствующий текст/уведомления. До этого репозиторий нельзя представлять как целиком MIT.

## Внешний MTProxy и зависимости

Официальный [TelegramMessenger/MTProxy](https://github.com/TelegramMessenger/MTProxy) запускается отдельным процессом и не поставляется в составе этого репозитория. Его код остаётся под условиями его авторов.

Rust-зависимости перечислены и зафиксированы в `Cargo.lock`; их лицензии не заменяются лицензией Qdynn-Bridge. При распространении собранных бинарников необходимо учитывать условия включённых зависимостей. Исходники сторонних библиотек не vendored в репозиторий.
